# Radix primitives only for overlay-heavy components

The frontend overhaul introduces a `components/ui/` primitives layer. We considered hand-rolling every primitive (as the codebase already did) versus adopting a full component kit. We chose a middle path: unstyled Radix primitives underpin only the components where correct behavior is hard to get right by hand — Dialog, Popover, Tooltip, DropdownMenu, Select (focus trapping, keyboard nav, portal/positioning) — while simpler presentational primitives (Button, Badge, Card, Input) stay hand-rolled Tailwind. A future contributor seeing Radix imported in some `ui/` components but not others should not assume the omission was an oversight; it reflects where the complexity actually justified the dependency, on a project explicitly scoped to avoid over-engineering.
