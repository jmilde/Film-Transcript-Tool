# Search is a global overlay, Chat is a dedicated route

As part of the frontend overhaul, Search and Ask needed to become reachable from anywhere (they were previously only reachable from the project page, not from `VideoWorkspace`). We considered making both overlays for consistency, but Chat carries a persistent left-hand conversation-history sidebar that wouldn't fit a drawer/overlay without cramping it or competing with the docked Document Panel for the same screen real estate. Search is lightweight (query + results list) and benefits from being summonable mid-task without losing place, so it becomes a command-palette-style overlay (⌘F) reachable from every page, while Chat stays a dedicated route but gains a persistent header entry point instead of being confined to the project page.
